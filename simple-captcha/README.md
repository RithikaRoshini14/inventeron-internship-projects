# Simple Captcha

This project is a simple captcha verification system built using HTML, CSS, and JavaScript.

## 🚀 Features
- Random captcha generation
- Canvas-based distorted captcha
- Case-insensitive validation
- Auto refresh on wrong input
- User-friendly interface

## 💻 Technologies Used
- HTML
- CSS
- JavaScript
